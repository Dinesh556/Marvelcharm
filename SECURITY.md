# Security Policy

## Supported Versions

Security updates are applied to the latest release of Marvel Desk Charm.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within Marvel Desk Charm:

1. **Do not disclose publicly**: Please avoid opening public issues for sensitive security vulnerabilities.
2. **Private Disclosure**: Report vulnerabilities by opening a private security advisory through the **Security** tab of this repository on GitHub.
3. **Information to Include**:
   - Description of the vulnerability.
   - Steps to reproduce the issue.
   - Expected vs actual behavior.
   - Any potential fixes or workarounds.

We take security seriously and will acknowledge receipt of your report within 48 hours, investigate promptly, and release a fix as soon as possible.
